Cosmic Ray Removal

Detection and cleaning with sigma-clipping, median filtering, and L.A.Cosmic.

Cosmic rays are high-energy particles that strike the detector during an exposure, leaving bright spots or streaks in the image. The fits_tools.image_processing.cosmic_rays module provides algorithms to detect and remove these artifacts.

Detection Methods

MethodDescriptionDependency
"sigma_clip"Sigma-clipping on residuals after median filteringSciPy
"median"Median-filter residual thresholdingSciPy
"lacosmic"L.A.Cosmic algorithm (van Dokkum 2001)astroscrappy

Check which methods are available in your installation:

from fits_tools.image_processing.cosmic_rays import get_available_methods

methods = get_available_methods()
print(f"Available methods: {methods}")

Detecting Cosmic Rays

detect_cosmic_rays returns three values: the cleaned image, a boolean mask (True = cosmic ray), and a dictionary of method diagnostics. sigma is the detection threshold in standard deviations:

from fits_tools import get_data
from fits_tools.image_processing.cosmic_rays import detect_cosmic_rays

data = get_data("science.fits")

cleaned, cr_mask, info = detect_cosmic_rays(data, method="sigma_clip", sigma=5.0)
print(f"Found {cr_mask.sum()} cosmic ray pixels")

Cleaning Cosmic Rays

Detect and replace cosmic ray pixels in one step. The result is a CosmicRayResult with cleaned_data, mask, num_cosmic_rays, and cosmic_ray_fraction:

from fits_tools.image_processing.cosmic_rays import reject_cosmic_rays

# Replace CR pixels with the local median (replace_with="median", the default)
result = reject_cosmic_rays(data, method="sigma_clip", sigma=5.0)
cleaned = result.cleaned_data
print(f"{result.num_cosmic_rays} pixels replaced "
      f"({result.cosmic_ray_fraction:.3%} of the image)")

File-Based Cleaning

Single File

from fits_tools.image_processing.cosmic_rays import clean_cosmic_rays_file

result = clean_cosmic_rays_file(
    "science.fits",
    output_file="cleaned.fits",
    method="sigma_clip",
    sigma=5.0,
    save_mask=True,      # also write the cosmic-ray mask
)
print(f"Removed {result.num_cosmic_rays} cosmic-ray pixels")

Batch Processing

from fits_tools.image_processing.cosmic_rays import batch_clean_cosmic_rays

files = ["sci_001.fits", "sci_002.fits", "sci_003.fits"]
summary = batch_clean_cosmic_rays(
    files,
    output_dir="cleaned/",
    method="sigma_clip",
    sigma=5.0,
)
print(f"{summary['successful']}/{summary['total_files']} files cleaned; "
      f"{summary['total_cosmic_rays']} cosmic-ray pixels in total")
for error in summary["errors"]:
    print("Failed:", error)

L.A.Cosmic

The L.A.Cosmic algorithm (Laplacian Cosmic Ray Identification) is the most sophisticated method, using edge detection to distinguish cosmic rays from real astronomical sources. It requires the astroscrappy package:

pip install astroscrappy

from fits_tools.image_processing.cosmic_rays import clean_cosmic_rays_file

result = clean_cosmic_rays_file(
    "science.fits",
    output_file="cleaned.fits",
    method="lacosmic",
)

Tune L.A.Cosmic with lacosmic_config=LACosmicConfig(...) (from the same module).

Choosing a threshold: The sigma parameter controls sensitivity. Lower values detect more cosmic rays but may also flag real signal. A value of 5.0 is a good starting point. For noisy data, try 7.0 or higher. For clean, high-SNR data, 3.0–4.0 may work better.
