Simulation

Generating synthetic calibration frames and injecting noise for testing.

The fits_tools.simulation subpackage generates realistic synthetic FITS data for testing calibration pipelines, validation routines, and image processing algorithms. It simulates common CCD/CMOS detector characteristics including read noise, photon noise, dark current, and detector artifacts.

Creating Synthetic Frames

Bias Frames

A bias frame is a zero-length exposure that measures the electronic offset (pedestal) of the detector:

from fits_tools.simulation.core import create_synthetic_bias

bias = create_synthetic_bias(
    shape=(2048, 2048),
    level=1000.0,        # pedestal level in ADU
    read_noise=5.0,      # read noise in electrons
    random_seed=42,      # for reproducibility
)

Dark Frames

A dark frame measures thermally generated signal (dark current):

from fits_tools.simulation.core import create_synthetic_dark

dark = create_synthetic_dark(
    shape=(2048, 2048),
    exptime=300.0,        # exposure time in seconds
    dark_current=0.01,    # electrons/pixel/second
    read_noise=5.0,
    random_seed=42,
)

Flat-Field Frames

A flat-field frame measures the pixel-to-pixel sensitivity variation:

from fits_tools.simulation.core import create_synthetic_flat

flat = create_synthetic_flat(
    shape=(2048, 2048),
    level=20000.0,         # mean signal level in ADU
    nonuniformity=0.05,    # 5% PRNU variation
    random_seed=42,
)

Science-Like Frames

from fits_tools.simulation.core import create_synthetic_science

science = create_synthetic_science(
    shape=(2048, 2048),
    signal_level=10000.0,
    background=100.0,
    read_noise=5.0,
    random_seed=42,
)

Writing Synthetic FITS Files

Create a complete FITS file with proper header keywords:

from fits_tools.simulation.core import create_synthetic_fits

create_synthetic_fits(
    "synthetic_bias.fits",
    image_type="BIAS",
    shape=(2048, 2048),
    exptime=0.0,
    header_keys={"GAIN": 1.5, "RDNOISE": 5.0, "DETECTOR": "TestCCD"},
)

Adding Noise to Existing Data

The fits_tools.simulation.noise module provides functions for injecting specific noise types into existing images:

Read Noise (Gaussian)

from fits_tools.simulation.noise import add_read_noise

noisy = add_read_noise(data, read_noise=5.0)

Photon Noise (Poisson)

Shot noise from photon statistics, proportional to the square root of the signal:

from fits_tools.simulation.noise import add_photon_noise

noisy = add_photon_noise(data, gain=1.5)

Dark Current

from fits_tools.simulation.noise import add_dark_current

noisy = add_dark_current(data, dark_current=0.01, exptime=300.0)

Detector Artifacts

from fits_tools.simulation.noise import add_hot_pixels, add_dead_pixels, add_cosmic_rays

# Inject hot pixels (fraction of total pixels)
data_with_hots = add_hot_pixels(data, fraction=0.001, intensity=10000.0)

# Inject dead pixels
data_with_deads = add_dead_pixels(data, fraction=0.0001)

# Inject cosmic ray hits
data_with_crs = add_cosmic_rays(data, rate=0.01, energy=1000.0)

Batch Noise Addition

The fits_tools.simulation.noise module also provides file-based noise injection:

from fits_tools.simulation.noise import add_gaussian_noise

add_gaussian_noise(
    "clean_image.fits",
    output="noisy_image.fits",
    sigma=10.0,
    seed=42,
)

Example: Testing a Calibration Pipeline

End-to-end test with synthetic data: 
from fits_tools.simulation.core import (
    create_synthetic_bias, create_synthetic_dark,
    create_synthetic_flat, create_synthetic_science,
)
from fits_tools.image_processing.calibration import apply_calibration
from fits_tools import array_stats

# Generate calibration frames
bias = create_synthetic_bias((1024, 1024), level=1000, read_noise=5, random_seed=1)
dark = create_synthetic_dark((1024, 1024), exptime=60, dark_current=0.05, random_seed=2)
flat = create_synthetic_flat((1024, 1024), level=30000, nonuniformity=0.03, random_seed=3)

# Generate a "raw" science frame (includes bias, dark, flat effects)
raw = create_synthetic_science((1024, 1024), signal_level=5000, random_seed=4)
raw = raw + bias + dark  # add instrumental signatures

# Calibrate
calibrated = apply_calibration(raw, master_bias=bias, master_dark=dark, master_flat=flat)

# Compare statistics
raw_stats = array_stats(raw)
cal_stats = array_stats(calibrated)
print(f"Before calibration: mean={raw_stats.mean_val:.1f}, std={raw_stats.std_val:.1f}")
print(f"After calibration:  mean={cal_stats.mean_val:.1f}, std={cal_stats.std_val:.1f}")
