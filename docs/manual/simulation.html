Simulation

Generating synthetic FITS frames and injecting noise for testing.

The fits_tools.simulation namespace creates realistic FITS files for pipeline tests. All generators write directly to the supplied path and accept a reproducible seed, including seed=0.

Creating Synthetic Frames

from fits_tools.simulation.core import (
    create_bias_frame,
    create_dark_frame,
    create_flat_frame,
    create_science_frame,
)

create_bias_frame(
    "bias.fits", shape=(2048, 2048),
    bias_level=1000.0, read_noise=5.0, seed=1,
)
create_dark_frame(
    "dark.fits", shape=(2048, 2048),
    exposure_time=300.0, dark_current=0.01, seed=2,
)
create_flat_frame(
    "flat.fits", shape=(2048, 2048),
    exposure_time=10.0, mean_level=20000.0, seed=3,
)
create_science_frame(
    "science.fits", shape=(2048, 2048),
    exposure_time=60.0, sky_level=100.0,
    num_stars=20, num_cosmic_rays=3, seed=4,
)

files = create_calibration_set(

create_mef_bias_frame(
    "mef_bias.fits",

Array-Level Noise and Artifacts

Array operations live in fits_tools.simulation.core and return new NumPy arrays.

from fits_tools.simulation.core import (
    add_cosmic_rays,
    add_hot_pixels,
    add_photon_noise,
    add_read_noise,
)

noisy = add_read_noise(data, read_noise=5.0, seed=1)
noisy = add_photon_noise(noisy, gain=1.5, seed=2)
noisy = add_hot_pixels(noisy, num_hot_pixels=20, seed=3)
noisy = add_cosmic_rays(noisy, num_cosmic_rays=5, seed=4)

Adding Noise to Existing FITS Files

The wrappers in fits_tools.simulation.noise read and write FITS files.

from fits_tools.simulation.noise import (
    add_gaussian_noise,
    add_poisson_noise,
)

add_gaussian_noise(
    "clean.fits", "gaussian.fits",
    sigma=10.0, hdu=0, seed=42,
)
add_poisson_noise(
    "clean.fits", "poisson.fits",
    gain=1.5, hdu=0, seed=42,
)

Example: Testing Calibration

from fits_tools import get_data_and_header
from fits_tools.image_processing.calibration import apply_calibration

raw, raw_header = get_data_and_header("science.fits")
bias, _ = get_data_and_header("bias.fits")
dark, dark_header = get_data_and_header("dark.fits")
flat, _ = get_data_and_header("flat.fits")

result = apply_calibration(
    raw,
    raw_header,
    master_bias_data=bias,
    master_dark_data=dark,
    master_dark_header=dark_header,
    master_flat_data=flat,
)
print(result.data.shape, result.corrections_applied)
