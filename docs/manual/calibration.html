The fits_tools.image_processing.calibration module provides the standard CCD/CMOS calibration pipeline: bias subtraction, dark subtraction (with exposure-time scaling), and flat-field division.

The Calibration Pipeline

The calibration sequence applied to each raw image is:

  1. Saturation flagging (optional): raw pixels ≥ saturation_level are flagged in the DQ mask
  2. Bias correction: image − master_bias
  3. Dark correction: (image − bias) − master_dark × (exptime / dark_exptime)
  4. Flat correction: (image − bias − dark) / normalized_flat
  5. Invalid-pixel flagging: any NaN/infinite result is set to 0 and flagged OUTLIER

Each step is optional. You can apply any combination of corrections depending on what calibration frames are available.

Calibrating a Single Image

calibrate_image

The primary entry point for file-based calibration:

from fits_tools.image_processing.calibration import calibrate_image

result = calibrate_image(
    "science_001.fits",
    master_bias="master_bias.fits",
    master_dark="master_dark.fits",
    master_flat="master_flat.fits",
)

# Access the calibrated data
print(f"Output shape: {result.data.shape}")
print(f"Output dtype: {result.data.dtype}")

Saturation is tested against the raw pixel values, before bias and dark subtraction, because detector and ADC saturation are properties of the raw readout. Pass the detector's raw limit (for example 65535 for a 16-bit ADC).

NaN in masters: master frames built with a bad-pixel mask contain NaN where no valid data existed. Flat statistics ignore non-finite pixels, and any pixel that is NaN or infinite after calibration is set to 0 and flagged OUTLIER in the DQ mask.

MEF-Preserving Calibration

Select repeated science extensions with both EXTNAME and EXTVER. Omitted master selectors inherit that resolved identity, so reordered master files are paired correctly rather than by HDU position.

# Copy the input MEF and replace only SCI, EXTVER=2.
result = calibrate_image(
    "raw_mef.fits",
    output_file="calibrated_mef.fits",
    master_bias="master_bias_mef.fits",
    hdu=("SCI", 2),
    output_mode="preserve",
)

# Transactionally replace the selected HDU in the raw file.
result = calibrate_image(
    "raw_mef.fits",
    master_bias="master_bias_mef.fits",
    hdu=("SCI", 2),
    output_mode="inplace",
)

Unrelated image and table extensions survive both modes. Data-quality output remains a sidecar file; it is not yet inserted into a DQ extension.

Plural MEF Calibration

calibrate_hdus calibrates several science extensions and commits all results together. Every master extension is paired by the resolved science identity, so reordered master MEFs are supported.

from fits_tools.hdu import HDUQuery
from fits_tools.image_processing.calibration import calibrate_hdus

results = calibrate_hdus(
    "raw_mef.fits",
    "calibrated_mef.fits",
    query=HDUQuery(extnames=frozenset({"SCI"})),
    master_bias="master_bias_mef.fits",
)

If any science/master pairing or destination validation fails, no selected science HDU is committed. Generated DQ arrays remain available on each returned result; the function does not implicitly create DQ extensions.

The function returns a CalibrationResult object:

Saving the Result

from fits_tools import write_simple_fits

# Option 1: specify output_file in the call
result = calibrate_image(
    "science.fits",
    output_file="calibrated.fits",
    master_bias="bias.fits",
)

# Option 2: write the result manually
result = calibrate_image("science.fits", master_bias="bias.fits")
write_simple_fits("calibrated_manual.fits", result.data, header=result.header)

In-Memory Calibration

apply_calibration

If you already have the data loaded as NumPy arrays, use apply_calibration to skip the file I/O:

from fits_tools.image_processing.calibration import apply_calibration
from fits_tools import get_data_and_header

raw, raw_header = get_data_and_header("science.fits")
bias, _ = get_data_and_header("master_bias.fits")
dark, dark_header = get_data_and_header("master_dark.fits")
flat, _ = get_data_and_header("master_flat.fits")

result = apply_calibration(
    raw,
    raw_header,
    master_bias_data=bias,
    master_dark_data=dark,
    master_dark_header=dark_header,
    master_flat_data=flat,
)
calibrated = result.data

preview_calibration

Quickly preview what calibration will do to an image without creating result objects:

from fits_tools.image_processing.calibration import preview_calibration

preview = preview_calibration(
    "science_mef.fits",
    master_bias="master_bias_mef.fits",
    master_flat="master_flat_mef.fits",
    hdu=("SCI", 2),
)
# preview is a dict of intermediate NumPy arrays

preview_calibration also accepts independent bias_hdu, dark_hdu, and flat_hdu selectors. Omitted selectors inherit the resolved raw science identity. Pass master_bpm (and optionally bpm_hdu) to exclude flagged pixels from the flat normalization exactly as calibrate_image does; the mask is returned as preview["bpm"]. With a region, the flat is still normalized by the whole frame's median, so the preview matches the same pixels of a full calibration.

Batch Calibration

calibrate_batch

Calibrate a list of files with the same master frames:

from fits_tools.image_processing.calibration import calibrate_batch
from pathlib import Path

science_files = list(Path("raw/").glob("science_*.fits"))

batch = calibrate_batch(
    science_files,
    output_dir="calibrated/",
    master_bias="masters/master_bias.fits",
    master_dark="masters/master_dark.fits",
    master_flat="masters/master_flat.fits",
    hdu=("SCI", 2),
    # Master selectors default to the science extension's identity;
    # these masters are single-image files, so select their primary HDU
    bias_hdu=0, dark_hdu=0, flat_hdu=0,
    num_workers=4,  # calibrate 4 frames at a time (threads)
)

print(f"Calibrated {batch.success_count} files")
for r in batch.results:
    print(f"  {r.input_file.name} -> {r.output_file.name}")

Batch calibration accepts independent bias_hdu, dark_hdu, flat_hdu, and bpm_hdu selectors. File-based masters are loaded once. For named, tuple, or automatic raw selection, every input must resolve to the same extension identity and shape as the first readable raw file before the cached masters are reused. Batch products remain standalone FITS images.

num_workers calibrates several frames at once in threads (default 1, serial). The masters are shared, so each extra worker adds only about one frame's memory; results keep the input order. On 24 2048×2048 frames, 4–8 workers were about 2.5× faster for plain calibration and about 4× faster with validate_inputs and compute_quality.

Partial Calibration

You can apply any subset of corrections. For example, to apply only bias and flat correction (no dark):

result = calibrate_image(
    "science.fits",
    master_bias="master_bias.fits",
    master_flat="master_flat.fits",
)

Or bias-only:

result = calibrate_image("science.fits", master_bias="master_bias.fits")

Creating Master Frames

Before calibration, you need master calibration frames. These are created by combining multiple individual frames. See the Image Combining chapter for details on create_master_frame.

Complete calibration workflow: 
from fits_tools.image_processing.combining import create_master_frame
from fits_tools.image_processing.calibration import calibrate_batch
from fits_tools.selection import select_bias_files, select_dark_files, select_flat_files, select_light_files

# 1. Select files by type
biases = select_bias_files("raw_data/")
darks  = select_dark_files("raw_data/")
flats  = select_flat_files("raw_data/")
lights = select_light_files("raw_data/")

# 2. Create master calibration frames (overwrite=True so the script can be re-run)
from pathlib import Path
Path("masters").mkdir(exist_ok=True)
bias_result = create_master_frame(biases, "bias", method="median",
                                  output_file="masters/master_bias.fits", overwrite=True)
dark_result = create_master_frame(darks, "dark", method="median",
                                  output_file="masters/master_dark.fits", overwrite=True)
flat_result = create_master_frame(flats, "flat", method="median", normalize=True,
                                  output_file="masters/master_flat.fits", overwrite=True)

# 3. Calibrate science frames
batch = calibrate_batch(
    lights,
    output_dir="calibrated/",
    master_bias="masters/master_bias.fits",
    master_dark="masters/master_dark.fits",
    master_flat="masters/master_flat.fits",
)

Exposure Time Scaling

Dark current scales linearly with exposure time. When the master dark frame has a different exposure time than the science image, the dark subtraction automatically reads the EXPTIME header keyword from both files and scales accordingly:

# If master_dark has EXPTIME=120 and science has EXPTIME=60,
# the dark contribution is scaled by 60/120 = 0.5
result = calibrate_image("science.fits", master_dark="master_dark.fits")
Warning: If the EXPTIME keyword is missing from either file, or the dark exposure time is zero, dark correction is skipped. Always ensure your FITS headers contain accurate exposure times.
