Image Combining

Median and mean combining, sigma-clipped stacking, and master frame creation.

Combining (stacking) multiple exposures is a fundamental step in astronomical image processing. It reduces noise, rejects artifacts like cosmic rays, and produces master calibration frames.

Why Combine Images?

  • Reduce noise: Combining N frames reduces random noise by a factor of √N.
  • Reject outliers: Cosmic rays, satellite trails, and hot pixels appear in different locations across frames. Median combining or sigma-clipping rejects them.
  • Create master frames: Master bias, dark, and flat frames are produced by combining many individual frames.

Creating Master Calibration Frames

create_master_frame

The recommended way to create master calibration frames from a set of FITS files:

from fits_tools.image_processing.combining import create_master_frame

# Create a master bias from a directory of bias frames
result = create_master_frame(
    "bias_frames/",
    frame_type="bias",
    method="median",
    output_file="master_bias.fits",
)
print(f"Combined {result.num_images} frames")

# From an explicit list of files
bias_files = ["bias_001.fits", "bias_002.fits", "bias_003.fits"]
result = create_master_frame(bias_files, frame_type="bias", method="median")

Combining Methods

Median Combine

Median combining computes the median value at each pixel position across all frames. It is excellent at rejecting outliers (cosmic rays, hot pixels) and is the standard method for creating master calibration frames:

from fits_tools.image_processing.combining import median_combine

# Combine arrays in memory
import numpy as np
frames = [np.random.normal(1000, 10, (512, 512)) for _ in range(10)]
combined = median_combine(frames)

Mean Combine

Mean combining computes the average at each pixel. It produces slightly lower noise than median combining but is more sensitive to outliers:

from fits_tools.image_processing.combining import mean_combine

combined = mean_combine(frames)

Sigma-Clipped Combine

combine_images sigma-clips outliers at each pixel before combining. The default method, "sigma_clipped_median", takes the median of the surviving values; "sigma_clipped_mean" takes their mean, giving close to the noise reduction of a mean combine with much of the outlier rejection of a median:

from fits_tools.image_processing.combining import combine_images

result = combine_images(
    frames,
    method="sigma_clipped_mean",
    sigma=3.0,     # reject values > 3 sigma from the centre
    maxiters=5,    # up to 5 clipping iterations
)
print(result.num_clipped, result.data.shape)

Clipping uses the standard deviation, so with very few frames a single outlier may not exceed the threshold: with N frames, one outlier can lie at most (N−1)/√N standard deviations from the mean.

Masks, Weights, and Missing Data

import numpy as np

bad_pixel_mask = np.zeros(frames[0].shape, dtype=bool)
bad_pixel_mask[100, 200] = True   # True = exclude this pixel

result = combine_images(
    frames,
    method="sigma_clipped_mean",
    mask=bad_pixel_mask,
    weights=np.linspace(1.0, 2.0, len(frames)),  # or "exptime" / "inverse_variance"
)
  • mask is honoured by every method. Pixels excluded in every frame have no valid data and are set to NaN in the result (choose another value with fill_value=). NCLIPPED counts only values rejected by clipping, not masked pixels.
  • weights apply to "mean", "weighted_mean", and "sigma_clipped_mean". Passing weights with "median" or "sigma_clipped_median" raises ValueError.
  • The result's data is always a plain NumPy array.

Combining MEF Extensions

Use an extension name and version to combine one logical detector segment across MEF files. The selector is resolved independently in every input, so the extension may appear at a different numeric position:

science_files = ["science_mef_001.fits", "science_mef_002.fits", "science_mef_003.fits"]

result = combine_images(
    science_files,
    method="sigma_clipped_median",
    hdu=("SCI", 2),
    return_type="result",
)

All selected HDUs must have the same normalized EXTNAME, EXTVER, HDU type, and shape. A missing extension, ambiguous bare name such as "SCI", or structural mismatch rejects the complete combine; files are not silently skipped. Numeric selectors remain available when position-based selection is intentional, but identity is still checked across the stack.

Plural MEF Combining

combine_image_hdus creates one stack for each selected logical extension and commits every combined result together:

from fits_tools.hdu import HDUQuery
from fits_tools.image_processing.combining import combine_image_hdus

results = combine_image_hdus(
    science_files,
    "combined_mef.fits",
    query=HDUQuery(extnames=frozenset({"SCI"})),
    method="sigma_clipped_median",
)

Extension identities are discovered from the first input and resolved independently in every later file. Missing, ambiguous, or incompatible partners abort the entire output transaction.

Which method to use?
  • Median — Good default for calibration frames. Simple, robust against outliers. Use when you have ≥ 5 frames.
  • Mean — Best noise reduction, but sensitive to outliers. Use only when data is clean or pre-filtered.
  • Sigma-clipped mean — Best overall when you have enough frames (≥ 7). Rejects outliers while preserving the noise benefit of averaging.

Streaming Combine (Large Datasets)

When your dataset is too large to fit in memory, the streaming combiner processes files one at a time using constant-memory algorithms:

from fits_tools.image_processing.streaming import streaming_combine

file_list = science_files  # any number of files

result = streaming_combine(
    file_list,
    method="mean",
    hdu=("SCI", 2),
    output_file="master.fits",
)

The streaming combiner uses Welford's algorithm for numerically stable online mean and variance computation. Memory usage is constant regardless of the number of input files.

Median: method="median" computes the exact per-pixel median. The image is processed in bands of rows: for each band only those rows are read from every file, so memory stays within max_memory_mb (default 1024) and total I/O is about one read of the dataset. Smaller budgets mean more, thinner bands.

Pass median_algorithm="p2" for the single-pass P² estimator instead. It is approximate: for stacks of tens of frames its error is comparable to the median's own sampling noise. The output header records the choice in MEDALG.

streaming_calibrated_combine bias- and dark-subtracts each frame as it is read, which is useful for building master flats or sky frames from large raw sets:

from fits_tools.image_processing.streaming import streaming_calibrated_combine

from pathlib import Path
from fits_tools import get_data, get_header_value

raw_files = sorted(Path("flat_frames/").glob("*.fits"))
bias = get_data("master_bias.fits")
dark = get_data("master_dark.fits")
bpm = get_data("detector_bpm.fits")

combined = streaming_calibrated_combine(
    raw_files,
    master_bias_data=bias,
    master_dark_data=dark,
    master_dark_exptime=get_header_value("master_dark.fits", "EXPTIME"),
    bad_pixel_mask=bpm,             # masked pixels are NaN in the result
    saturation_threshold_adu=65000, # raw ADU
    max_saturated_pixels=0,         # reject frames with any saturated pixel
    output_file="master_flat_raw.fits",
)

Rejected frames are logged by filename, and the output header records NREJSAT (frames rejected) and SATLEVEL.

The hdu argument accepts the standard selector forms. Selection is resolved independently in every file, and extension identity and shape must agree before accumulation. Named/versioned selectors therefore work when MEF extensions are reordered.

File Selection Helpers

The fits_tools.selection module provides convenience functions for selecting calibration frames by type:

from fits_tools.selection import (
    select_bias_files,
    select_dark_files,
    select_flat_files,
    select_light_files,
    select_files,
)

# Select by image type
biases = select_bias_files("data/", recursive=True)
darks  = select_dark_files("data/")
flats  = select_flat_files("data/")

# Select with custom header filtering
files = select_files(
    "data/",
    keys={"IMAGETYP": "LIGHT", "FILTER": "R"},
    recursive=True,
)
