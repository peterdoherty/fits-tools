Image Combining

Median and mean combining, sigma-clipped stacking, and master frame creation.

Combining (stacking) multiple exposures is a fundamental step in astronomical image processing. It reduces noise, rejects artifacts like cosmic rays, and produces master calibration frames.

Why Combine Images?

  • Reduce noise: Combining N frames reduces random noise by a factor of √N.
  • Reject outliers: Cosmic rays, satellite trails, and hot pixels appear in different locations across frames. Median combining or sigma-clipping rejects them.
  • Create master frames: Master bias, dark, and flat frames are produced by combining many individual frames.

Creating Master Calibration Frames

create_master_frame

The recommended way to create master calibration frames from a set of FITS files:

from fits_tools.image_processing.combining import create_master_frame

# Create a master bias from a directory of bias frames
result = create_master_frame(
    "bias_frames/",
    method="median",
    output_path="master_bias.fits",
)
print(f"Combined {result.n_images} frames")

# From an explicit list of files
bias_files = ["bias_001.fits", "bias_002.fits", "bias_003.fits"]
result = create_master_frame(bias_files, method="median")

Combining Methods

Median Combine

Median combining computes the median value at each pixel position across all frames. It is excellent at rejecting outliers (cosmic rays, hot pixels) and is the standard method for creating master calibration frames:

from fits_tools.image_processing.combining import median_combine

# Combine arrays in memory
import numpy as np
frames = [np.random.normal(1000, 10, (512, 512)) for _ in range(10)]
combined = median_combine(frames)

Mean Combine

Mean combining computes the average at each pixel. It produces slightly lower noise than median combining but is more sensitive to outliers:

from fits_tools.image_processing.combining import mean_combine

combined = mean_combine(frames)

Sigma-Clipped Combine

For the best of both worlds, combine_images_robust uses sigma-clipping to reject outliers before computing the mean. This gives the noise reduction of mean combining with the outlier rejection of median combining:

from fits_tools.image_processing.combining import combine_images_robust

combined = combine_images_robust(
    frames,
    sigma=3.0,     # reject pixels > 3 sigma from the mean
    maxiters=5,    # up to 5 clipping iterations
)
Which method to use?
  • Median — Good default for calibration frames. Simple, robust against outliers. Use when you have ≥ 5 frames.
  • Mean — Best noise reduction, but sensitive to outliers. Use only when data is clean or pre-filtered.
  • Sigma-clipped mean — Best overall when you have enough frames (≥ 7). Rejects outliers while preserving the noise benefit of averaging.

Streaming Combine (Large Datasets)

When your dataset is too large to fit in memory, the streaming combiner processes files one at a time using constant-memory algorithms:

from fits_tools.image_processing.streaming import streaming_combine

result = streaming_combine(
    file_list,
    method="mean",
    output_path="master.fits",
)

The streaming combiner uses Welford's algorithm for numerically stable online mean and variance computation. Memory usage is constant regardless of the number of input files.

File Selection Helpers

The fits_tools.selection module provides convenience functions for selecting calibration frames by type:

from fits_tools.selection import (
    select_bias_files,
    select_dark_files,
    select_flat_files,
    select_light_files,
    select_files,
)

# Select by image type
biases = select_bias_files("data/", recursive=True)
darks  = select_dark_files("data/")
flats  = select_flat_files("data/")

# Select with custom header filtering
files = select_files(
    "data/",
    keys={"IMAGETYP": "LIGHT", "FILTER": "R"},
    recursive=True,
)
