Headers & Keywords

Checking, reading, setting, and deleting FITS header keywords.

The fits_tools.keywords module provides functions for managing FITS header keywords. Every FITS file contains a header with keyword-value pairs that describe the data (exposure time, detector settings, object name, etc.). These functions let you read and modify those keywords without manually opening and closing files.

Single-File Operations

Checking if a Keyword Exists

from fits_tools import check_keyword

if check_keyword("image.fits", "EXPTIME"):
    print("EXPTIME keyword is present")
else:
    print("EXPTIME keyword is missing")

Getting a Keyword Value

from fits_tools import get_key

exptime = get_key("image.fits", "EXPTIME")
print(f"Exposure time: {exptime} seconds")

# Read from a specific HDU by index
gain = get_key("image.fits", "GAIN", hdu=1)

# Read from an HDU by extension name
gain = get_key("image.fits", "GAIN", hdu="SCI")

# Read from a specific extension version
gain = get_key("image.fits", "GAIN", hdu=("SCI", 2))
HDU selection: All keyword functions accept an hdu parameter. It can be an integer index (0 for the primary HDU), a string extension name ("SCI"), a tuple of name and version (("SCI", 2)), or the string "auto" (the default, which selects the primary HDU).

Setting a Keyword

Set or update a keyword value. If the keyword already exists, its value is replaced. If it does not exist, it is added:

from fits_tools import set_key

# Set a simple keyword
set_key("image.fits", "PROCESSED", True, comment="Calibration applied")

# Set a keyword with a specific value type
set_key("image.fits", "EXPTIME", 120.0, comment="Exposure time in seconds")

# Set a keyword in a specific HDU
set_key("image.fits", "GAIN", 1.5, hdu=1)

filepathstr or Path—Path to the FITS file
keywordstr—Keyword name (up to 8 characters)
valueany—Value to assign
commentstr or NoneNoneOptional comment string
hduint, str, tuple, or "auto""auto"HDU to modify

Deleting a Keyword

from fits_tools import delete_key

# Remove a keyword from the primary header
delete_key("image.fits", "COMMENT")

Batch Operations

Batch operations apply changes to multiple files at once. They accept a directory path, a glob pattern, or a list of file paths.

batch_set_key

Set a keyword across many files:

from fits_tools import batch_set_key

# Set keyword in all FITS files in a directory
count = batch_set_key("data/", "PIPELINE", "v2.1.0")
print(f"Updated {count} files")

# Recursive search through subdirectories
count = batch_set_key("data/", "PIPELINE", "v2.1.0", recursive=True)

# Only update files matching specific header criteria
count = batch_set_key(
    "data/*.fits",
    "CALIBRATED",
    True,
    keys={"IMAGETYP": "LIGHT"},
)
print(f"Marked {count} light frames as calibrated")
The keys parameter acts as a filter. Only files whose header keywords match the specified values are modified. For example, keys={"IMAGETYP": "LIGHT"} restricts the operation to files where the IMAGETYP keyword equals "LIGHT" (case-insensitive).

batch_delete_key

Delete a keyword from many files:

from fits_tools import batch_delete_key

# Remove COMMENT cards from all FITS files
count = batch_delete_key("data/", "COMMENT", recursive=True)
print(f"Cleaned {count} files")

FITS Keyword Naming Rules

FITS keyword names follow these rules from the FITS standard:

  • Maximum 8 characters (or longer with the HIERARCH convention)
  • Uppercase letters, digits, hyphens, and underscores only
  • Commentary keywords (COMMENT, HISTORY) can appear multiple times and have no assigned value

Standard Keywords

The fits_tools.constants module defines named constants for common FITS keywords. Using these instead of string literals avoids typos:

from fits_tools.constants import (
    FITS_KEY_EXPTIME,    # "EXPTIME"
    FITS_KEY_IMAGETYP,   # "IMAGETYP"
    FITS_KEY_GAIN,       # "GAIN"
    FITS_KEY_RDNOISE,    # "RDNOISE"
    FITS_KEY_OBJECT,     # "OBJECT"
    FITS_KEY_DATASEC,    # "DATASEC"
    FITS_KEY_BIASSEC,    # "BIASSEC"
)

See the API Reference for the full list.

Error Handling

from fits_tools import get_key
from fits_tools.exceptions import HeaderKeywordError

try:
    value = get_key("image.fits", "NONEXIST")
except HeaderKeywordError as e:
    print(f"Keyword not found: {e.keyword}")
