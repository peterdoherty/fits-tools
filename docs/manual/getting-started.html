Prerequisites

fits_tools requires Python 3.11 or later. You can check your Python version by running:

python --version

If you do not have Python 3.11+, install it from python.org or via your system package manager.

Installation

From Source (Recommended for Development)

Clone the repository and install in editable (development) mode:

git clone https://github.com/peterdoherty/fits-tools.git
cd fits-tools
pip install -e .

This installs the package so that changes you make to the source code take effect immediately without reinstalling.

With Development Tools

To also install testing and linting tools (pytest, ruff, mypy):

pip install -e ".[dev]"

With Optional Extras

Install progress bar support and/or plotting:

# Progress bars for batch operations
pip install -e ".[progress]"

# Plotting support
pip install -e ".[plotting]"

# Everything
pip install -e ".[dev,progress,plotting]"

Verifying the Installation

Open a Python interpreter and import the package:

import fits_tools
print(fits_tools.__version__)
# Expected output: 0.1.0

Key Concepts

What is a FITS File?

FITS (Flexible Image Transport System) is the standard file format used in astronomy for storing images, tables, and metadata. A FITS file is organized into one or more Header Data Units (HDUs):

  • Primary HDU (index 0) — Always present. Contains an optional image array and a header with metadata.
  • Image Extensions — Additional image arrays, each with their own header. Common in multi-amplifier or multi-chip detectors.
  • Table Extensions — Binary or ASCII tables for catalog data.

Each HDU has a header consisting of keyword-value pairs. Standard keywords include NAXIS1 and NAXIS2 (image dimensions), BITPIX (data type), EXPTIME (exposure time), and IMAGETYP (frame type such as BIAS, DARK, FLAT, or LIGHT).

CCD Calibration Overview

Raw images from CCD and CMOS detectors contain instrumental signatures that must be removed before scientific analysis. The standard calibration steps are:

  1. Bias subtraction — Remove the electronic offset (pedestal) by subtracting a master bias frame.
  2. Dark subtraction — Remove thermally generated signal (dark current) by subtracting a scaled master dark frame.
  3. Flat-field division — Correct for pixel-to-pixel sensitivity variations by dividing by a normalized master flat frame.

Master calibration frames are typically created by combining (stacking) multiple individual frames to reduce noise.

Your First Script

Here is a complete example that reads a FITS file, prints basic statistics, and writes a copy:

from fits_tools import get_data_and_header, write_simple_fits, stats

# Read the primary HDU data and header
data, header = get_data_and_header("my_image.fits")
print(f"Image shape: {data.shape}")
print(f"Data type:   {data.dtype}")

# Compute and print statistics
result = stats("my_image.fits")
print(result)

# Write a copy
write_simple_fits(data, "copy.fits", header=header)

Common Import Patterns

Most functions are available directly from the top-level fits_tools namespace:

# Top-level imports (most common functions)
from fits_tools import (
    get_data, get_header, get_data_and_header,
    write_simple_fits,
    stats, robust_stats, array_stats,
    get_key, set_key, check_keyword,
    validate_fits_file, quick_validate,
)

For image processing, import from the subpackage:

# Calibration
from fits_tools.image_processing.calibration import calibrate_image

# Combining
from fits_tools.image_processing.combining import (
    combine_images_robust, create_master_frame,
)

# Transformations
from fits_tools.image_processing.transformations import (
    crop_image, bin_image, normalize_image,
)

# Cosmic rays
from fits_tools.image_processing.cosmic_rays import (
    detect_cosmic_rays, clean_cosmic_rays_file,
)

For defect detection:

from fits_tools.defects import (
    create_calibration_bpm,
    detect_hot_pixels,
    save_bpm_to_fits,
    load_bpm_from_fits,
)

Getting Help

Every public function has a docstring. Use Python's built-in help() function to read it:

from fits_tools import stats
help(stats)
