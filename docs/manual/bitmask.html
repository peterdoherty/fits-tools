Bad Pixel Masks

The 32-bit bitmask system, defect flags, combined masks, and mask utilities.

A Bad Pixel Mask (BPM) is an integer array the same size as the detector image where each pixel encodes which types of defects are present at that location. fits_tools uses a 32-bit unsigned integer (uint32) per pixel, with individual bits assigned to specific defect types. A single pixel can carry multiple defect flags simultaneously via bitwise OR.

Bitmask Architecture

The 32 bits are organized into three logical zones:

BitsZonePurpose
0–15Pixel-levelStatic hardware defects for individual pixels
16–26StructuralColumn-level and row-level defects
27–31TransientPer-exposure data quality flags

3BPM_BIT_PIX_HOTExcessive dark current
4BPM_BIT_PIX_PRNU_HIGHHigh sensitivity (PRNU outlier)
5BPM_BIT_PIX_PRNU_LOWLow sensitivity (PRNU outlier)
6BPM_BIT_PIX_NONLINNon-linear response
7BPM_BIT_PIX_NOISEExcessive read noise
8BPM_BIT_PIX_RTSRandom Telegraph Signal (temporal instability)
9BPM_BIT_PIX_TRAPIndividual charge trap
10BPM_BIT_PIX_GLOWAmplifier / circuitry glow
11BPM_BIT_PIX_CLUSTERPart of a defect cluster
15BPM_BIT_PIX_EXCLUDEDManually excluded from statistics

Combined Masks

Combined masks are pre-defined bitwise OR combinations for common use cases:

ConstantDescription
BPM_MASK_PERMANENTAll permanent hardware defects (pixel + structural)
BPM_MASK_TRANSIENTPer-exposure artifacts (cosmic, saturated, etc.)
BPM_MASK_HOTAll high-signal anomalies
BPM_MASK_COLDAll dead / cold / blocked defects
BPM_MASK_NOISETemporal noise and instability
BPM_MASK_TRANSPORTCharge transport defects (traps, CTE, blocked)
BPM_MASK_BADGeneral bad flags (pixel, row, column)
BPM_MASK_IGNOREExplicitly excluded from statistics
BPM_MASK_ALLAll 32 bits

Creating and Manipulating Masks

Creating an Empty BPM

from fits_tools import get_data
from fits_tools.bitmask import create_bpm, BPM_BIT_PIX_HOT, BPM_BIT_PIX_DEAD

data = get_data("image.fits")

# Create a blank (all-good) mask with the same shape as the image
bpm = create_bpm(data.shape)

# Flag a hot pixel at (row=100, col=200)
bpm[100, 200] |= BPM_BIT_PIX_HOT

# Flag a dead pixel
bpm[500, 300] |= BPM_BIT_PIX_DEAD

# Flag a pixel with multiple defects
bpm[100, 200] |= BPM_BIT_PIX_DEAD  # now hot AND dead

Querying Pixel Status

from fits_tools.bitmask import (
    is_perfect_pixel, is_usable_pixel, has_defect,
    describe_pixel_defects, BPM_BIT_PIX_HOT,
)

value = int(bpm[100, 200])

# Is this pixel completely clean?
print(is_perfect_pixel(value))  # False

# Is it usable? By default only permanent hardware defects count;
# pass ignore_transient=False to also reject transient DQ flags.
print(is_usable_pixel(value))   # False (hot and dead)

# Does it have a specific defect?
print(has_defect(value, BPM_BIT_PIX_HOT))  # True

# Human-readable description
print(describe_pixel_defects(value))

Boolean Masks

from fits_tools.bitmask import (
    build_good_pixel_mask, get_defect_mask, BPM_MASK_HOT, BPM_BIT_PIX_DEAD,
)

# True = good pixel: no permanent defect in the BPM and not NaN in the data
good = build_good_pixel_mask(data, bad_pixel_mask=bpm)

# True = has any defect
bad = get_defect_mask(bpm)

# True = has one of the listed defect bits or group masks
hot_mask = get_defect_mask(bpm, defect_types=[BPM_MASK_HOT])
dead_mask = get_defect_mask(bpm, defect_types=[BPM_BIT_PIX_DEAD])

Applying a BPM to Data

import numpy as np
from fits_tools.bitmask import apply_bpm, BPM_MASK_HOT

# Replace pixels with permanent defects by NaN (the default)
cleaned = apply_bpm(data, bpm)

# Replace them with zero instead
cleaned = apply_bpm(data, bpm, fill_value=0.0)

# Only replace pixels with hot-pixel flags
cleaned = apply_bpm(data, bpm, defect_mask=BPM_MASK_HOT, fill_value=np.nan)

Merging Multiple BPMs

from fits_tools.bitmask import create_bpm, merge_bpms, BPM_BIT_PIX_HOT, BPM_BIT_PIX_DEAD

bpm_dark = create_bpm(data.shape)
bpm_dark[10, 10] |= BPM_BIT_PIX_HOT
bpm_flat = create_bpm(data.shape)
bpm_flat[20, 20] |= BPM_BIT_PIX_DEAD

# Union of flags (bitwise OR), the default
combined = merge_bpms(bpm_dark, bpm_flat)

# Other strategies: "and", "xor" (what changed), "diff" (in first, not second)
changed = merge_bpms(bpm_dark, bpm_flat, operation="xor")

Statistics

from fits_tools.bitmask import get_bpm_statistics

stats = get_bpm_statistics(bpm)
for flag_name, entry in stats.items():
    print(f"{flag_name}: {entry['count']} pixels ({entry['fraction']*100:.3f}%)")

Flagging Rows, Columns, and Borders

from fits_tools.bitmask import (
    flag_bad_rows_cols,
    flag_excluded_border,
    flag_excluded_rows,
    flag_excluded_cols,
)

# Promote rows/columns where more than 10% of pixels are defective
# to ROW_BAD / COL_BAD flags
bpm = flag_bad_rows_cols(bpm, row_threshold=0.1, col_threshold=0.1)

# Exclude a 10-pixel border (rows at top/bottom, columns at left/right)
bpm = flag_excluded_border(bpm, nrows=10, ncols=10)

# Exclude specific rows/columns from measurements
bpm = flag_excluded_rows(bpm, rows=[0, 1])
bpm = flag_excluded_cols(bpm, cols=[0, 1])

The DefectType Enum

For type-safe access, DefectType is an IntFlag enum that maps bit positions to named members:

from fits_tools.bitmask import DefectType

# DefectType is an IntFlag; convert NumPy integers with int()
status = DefectType(int(bpm[100, 200]))
print(status)

# Use as a flag
if DefectType.PIX_HOT in status:
    print("Pixel is hot")
