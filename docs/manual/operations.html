Image Operations

Arithmetic, unary functions, masking, thresholding, and bitwise operations.

The fits_tools.image_processing.operations module provides pixel-wise operations. Two-image arithmetic works on FITS files and writes a new file; the scalar, unary, masking, and bitwise helpers work on NumPy arrays; apply_operation_to_file applies any array operation to a FITS file.

The array examples below use an image loaded with:

from fits_tools import get_data

data = get_data("image.fits")

Image Arithmetic (Files)

Combine two FITS images pixel by pixel. Each function writes output_file and returns an ImageOperationResult. Errors are reported through the result rather than raised, so check success (and error):

from fits_tools.image_processing.operations import (
    add_images, subtract_images, multiply_images, divide_images,
)

total   = add_images("science.fits", "background.fits", "sum.fits")
diff    = subtract_images("science.fits", "background.fits", "diff.fits")
product = multiply_images("science.fits", "background.fits", "product.fits")
ratio   = divide_images("science.fits", "background.fits", "ratio.fits",
                        fill_value=0.0)

if not diff.success:
    raise RuntimeError(diff.error)
difference = get_data(diff.output_file)
Division safety: divide_images replaces the result with fill_value (default 0.0) wherever the denominator is zero.

All file functions accept hdu (and operand_hdu for the second file), overwrite, and the MEF output_mode options.

Scalar Arithmetic

Apply an operation between an array and a scalar:

from fits_tools.image_processing.operations import (
    apply_scalar_operation, scale_image,
)

brighter = apply_scalar_operation(data, "add", 100.0)
doubled  = apply_scalar_operation(data, "multiply", 2.0)
root     = apply_scalar_operation(data, "power", 0.5)

# File convenience: scale a FITS image and write the result
result = scale_image("image.fits", 2.5, "scaled.fits")

Available scalar operations:

NameOperation
"add"image + value
"subtract"image − value
"multiply"image × value
"divide", "true_divide"image / value
"floor_divide"image // value
"power"image ^ value
"mod", "remainder"image mod value

Scalar and unary operations accept a bad_pixel_mask; masked pixels (and NaN, by default) are left unchanged.

Unary Operations

Apply a mathematical function to every pixel:

from fits_tools.image_processing.operations import apply_unary_operation

log_image  = apply_unary_operation(data, "log10")
sqrt_image = apply_unary_operation(data, "sqrt")
abs_image  = apply_unary_operation(data, "abs")
neg_image  = apply_unary_operation(data, "negate")

Available unary operations include: log, log10, log2, sqrt, abs, negate, exp, sin, cos, tan, round, floor, ceil, and more. Use list_operations("unary") to see the full list.

Masking and Thresholding

Creating Masks

create_mask compares each pixel with a threshold and returns a boolean array. Comparisons are "greater", "greater_equal", "less", "less_equal", "equal", and "not_equal":

import numpy as np
from fits_tools.image_processing.operations import create_mask

high_mask = create_mask(data, "greater", 50000)   # bright/saturated pixels
low_mask  = create_mask(data, "less", 100)        # very low pixels
nan_mask  = np.isnan(data)                         # NaN pixels

Thresholding

from fits_tools.image_processing.operations import threshold_image

binary    = threshold_image(data, 1000)                     # 1.0 where >= 1000, else 0.0
floored   = threshold_image(data, 100, mode="zero")         # pixels < 100 set to 0
truncated = threshold_image(data, 60000, mode="truncate")   # pixels > 60000 set to 60000

Modes: "binary" (default), "zero", "truncate", and "to_zero_inv" (pixels ≥ threshold set to 0).

Conditional Fill

from fits_tools.image_processing.operations import fill_where, fill_masked

# Replace pixels below 0 with 0
clean = fill_where(data, "less", 0, 0.0)

# Fill wherever a boolean mask is True
clean = fill_masked(data, high_mask, 0.0)

Setting Pixel Values

Use NumPy indexing to set individual pixels or regions (row, column order); set_value sets every pixel of an array:

from fits_tools.image_processing.operations import set_value

modified = data.copy()
modified[100, 200] = 0.0          # one pixel
modified[0:10, :] = 0.0           # first ten rows

blank = set_value(data, 0.0)      # same shape, every pixel 0.0

Bitwise Operations

Useful for working with data quality arrays and bitmasks. Operations are "bitwise_and", "bitwise_or", "bitwise_xor", "bitwise_not", "left_shift", and "right_shift":

from fits_tools import get_data
from fits_tools.image_processing.operations import apply_bitwise_operation

bpm = get_data("detector_bpm.fits")

low_bits = apply_bitwise_operation(bpm, "bitwise_and", 0xFF)   # keep low 8 bits
flagged  = apply_bitwise_operation(bpm, "bitwise_or", 0x01)    # set bit 0
toggled  = apply_bitwise_operation(bpm, "bitwise_xor", 0x01)   # toggle bit 0

File-Based Operations

apply_operation_to_file applies a unary, scalar, comparison, bitwise, or fill operation to a FITS file. Choose the category with operation_type and supply the matching argument (scalar, threshold, or operand):

from fits_tools.image_processing.operations import apply_operation_to_file

# Multiply a FITS image by 2
result = apply_operation_to_file(
    "image.fits",
    "scaled.fits",
    operation_type="scalar",
    operation="multiply",
    scalar=2.0,
)

# Write a 0/1 mask of pixels above 50000
result = apply_operation_to_file(
    "image.fits",
    "bright_mask.fits",
    operation_type="comparison",
    operation="greater",
    threshold=50000,
)

# Skip flagged pixels using a bad-pixel mask file
result = apply_operation_to_file(
    "image.fits",
    "log_image.fits",
    operation_type="unary",
    operation="log10",
    bad_pixel_mask_file="detector_bpm.fits",
)
print(result.success, result.output_file)

To subtract one image from another, use subtract_images (above).

Listing Available Operations

from fits_tools.image_processing.operations import list_operations

# List all categories
all_ops = list_operations()

# List operations in a specific category
unary_ops = list_operations("unary")
scalar_ops = list_operations("scalar")
