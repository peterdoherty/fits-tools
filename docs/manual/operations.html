Image Operations

Arithmetic, unary functions, masking, thresholding, and bitwise operations.

The fits_tools.image_processing.operations module provides pixel-wise operations on images. All operations work on NumPy arrays and can also be applied directly to FITS files.

Binary Image Arithmetic

Combine two images pixel-by-pixel:

from fits_tools.image_processing.operations import (
    add_images, subtract_images, multiply_images, divide_images,
)

sum_image  = add_images(image1, image2)
diff       = subtract_images(image1, image2)
product    = multiply_images(image1, image2)
ratio      = divide_images(image1, image2, zero_value=0.0)
Division safety: divide_images handles division by zero by replacing the result with zero_value (default 0.0) wherever the denominator is zero.

Scalar Arithmetic

Apply an operation between an image and a scalar value:

from fits_tools.image_processing.operations import (
    apply_scalar_operation, scale_image,
)

# Using the general function
result = apply_scalar_operation(data, "add", 100.0)
result = apply_scalar_operation(data, "multiply", 2.5)
result = apply_scalar_operation(data, "power", 0.5)  # square root

# Convenience shortcut for scaling
scaled = scale_image(data, factor=2.5)

Available scalar operations:

NameOperation
"add"image + value
"subtract"image − value
"multiply"image × value
"divide"image / value
"power"image ^ value
"mod"image mod value
"clip_min"max(image, value)
"clip_max"min(image, value)

Unary Operations

Apply a mathematical function to every pixel:

from fits_tools.image_processing.operations import apply_unary_operation

log_image  = apply_unary_operation(data, "log10")
sqrt_image = apply_unary_operation(data, "sqrt")
abs_image  = apply_unary_operation(data, "abs")
neg_image  = apply_unary_operation(data, "negate")

Available unary operations include: log, log10, log2, sqrt, abs, negate, exp, sin, cos, tan, round, floor, ceil, and more. Use list_operations("unary") to see the full list.

Masking and Thresholding

Creating Masks

from fits_tools.image_processing.operations import create_mask

# Mask pixels above a threshold
high_mask = create_mask(data.shape, "above", threshold=50000)

# Mask pixels below a threshold
low_mask = create_mask(data.shape, "below", threshold=100)

# Mask NaN values
nan_mask = create_mask(data.shape, "nan")

Thresholding

from fits_tools.image_processing.operations import threshold_image

# Set all pixels below 100 to zero
clipped = threshold_image(data, threshold=100, value=0.0)

Conditional Fill

from fits_tools.image_processing.operations import fill_where, fill_masked

# Replace NaN pixels with zero
clean = fill_where(data, "nan", 0.0)

# Replace pixels below threshold
clean = fill_where(data, "below", 0.0, threshold=0)

# Fill using a boolean mask
clean = fill_masked(data, bad_pixel_mask, value=0.0)

Setting Individual Pixels

from fits_tools.image_processing.operations import set_value

# Set a specific pixel (row, col) to a value
modified = set_value(data, row=100, col=200, value=0.0)

Bitwise Operations

Useful for working with data quality arrays and bitmasks:

from fits_tools.image_processing.operations import apply_bitwise_operation

# AND with a mask
masked = apply_bitwise_operation(bpm, "and", 0xFF)

# OR to set flags
flagged = apply_bitwise_operation(bpm, "or", 0x01)

# XOR to toggle flags
toggled = apply_bitwise_operation(bpm, "xor", 0x01)

File-Based Operations

Apply any operation directly to a FITS file:

from fits_tools.image_processing.operations import apply_operation_to_file

# Scale a FITS file
result = apply_operation_to_file(
    "image.fits",
    operation="multiply",
    value=2.0,
    output_path="scaled.fits",
)

# Subtract one image from another
result = apply_operation_to_file(
    "science.fits",
    operation="subtract",
    second_file="background.fits",
    output_path="subtracted.fits",
)

Listing Available Operations

from fits_tools.image_processing.operations import list_operations

# List all categories
all_ops = list_operations()

# List operations in a specific category
unary_ops = list_operations("unary")
scalar_ops = list_operations("scalar")
