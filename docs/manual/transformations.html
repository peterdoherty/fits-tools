Transformations

Cropping, binning, rotation, flipping, normalization, and intensity rescaling.

The fits_tools.image_processing.transformations module provides geometric and intensity transformations for images.

Geometric Transformations

Cropping

Extract a rectangular sub-region from an image:

from fits_tools.image_processing.transformations import crop_image

# Crop using (start_col, end_col, start_row, end_row)
cropped = crop_image(data, region=(100, 900, 100, 900))
print(f"Cropped shape: {cropped.shape}")  # (800, 800)

Binning

Reduce image resolution by averaging groups of pixels. A bin factor of 2 combines each 2×2 block into a single pixel, reducing the image dimensions by half:

from fits_tools.image_processing.transformations import bin_image

# Bin 2x2 (reduces 2048x2048 to 1024x1024)
binned = bin_image(data, bin_factor=2, method="mean")

# Bin 4x4 with sum mode (preserves total flux)
binned = bin_image(data, bin_factor=4, method="sum")

Rotation

from fits_tools.image_processing.transformations import rotate_image

# Rotate by 90 degrees
rotated = rotate_image(data, angle=90)

# Rotate by an arbitrary angle (uses interpolation)
rotated = rotate_image(data, angle=15.5)

# Allow the output shape to grow to contain the full rotated image
rotated = rotate_image(data, angle=45, preserve_shape=False)

Flipping

from fits_tools.image_processing.transformations import flip_image

# Flip vertically (top to bottom)
flipped = flip_image(data, axis=0)

# Flip horizontally (left to right)
flipped = flip_image(data, axis=1)

Transposing

from fits_tools.image_processing.transformations import transpose_image

# Swap rows and columns
transposed = transpose_image(data)

Intensity Transformations

Normalization

Scale pixel values to a standard range:

from fits_tools.image_processing.transformations import normalize_image

# Normalize to [0, 1] using min-max scaling
normalized = normalize_image(data, method="minmax")

# Normalize by the median (result centered at 1.0)
normalized = normalize_image(data, method="median", target_value=1.0)

# Normalize by the mean
normalized = normalize_image(data, method="mean")
Flat-field normalization: When creating master flat frames, the standard practice is to normalize by the median so that the flat has a median value of 1.0. Dividing by this normalized flat corrects pixel-to-pixel sensitivity variations without changing the overall flux level.

Intensity Rescaling

from fits_tools.image_processing.transformations import rescale_intensity

# Rescale to a specific output range
rescaled = rescale_intensity(data, out_range=(0, 65535))

# Rescale with an input range (clips values outside)
rescaled = rescale_intensity(data, in_range=(100, 50000), out_range=(0, 1))

Inversion

from fits_tools.image_processing.transformations import invert_image

# Reverse intensity (max becomes min, min becomes max)
inverted = invert_image(data)

File-Based Transformations

Apply a transformation directly to a FITS file and save the result:

from fits_tools.image_processing.transformations import transform_image_file

result = transform_image_file(
    "image.fits",
    operation="crop",
    param=(100, 900, 100, 900),
    output_path="cropped.fits",
)
