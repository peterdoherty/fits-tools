Welcome

fits_tools is a Python library for working with FITS (Flexible Image Transport System) files, the standard data format used in astronomy. It provides tools for reading and writing FITS files, managing header keywords, computing image statistics, calibrating CCD/CMOS data, detecting defects, and performing image processing operations.

The library is built on top of Astropy, NumPy, and SciPy, and is designed for scientists and engineers working with CCD and CMOS detector data.

Quick Example

from fits_tools import get_data_and_header, write_simple_fits, stats
from fits_tools.image_processing.calibration import calibrate_image

# Read a FITS file
data, header = get_data_and_header("image.fits")

# Compute statistics
result = stats("image.fits")
print(result)

# Calibrate an image (bias, dark, flat correction)
cal_result = calibrate_image(
    "image.fits",
    master_bias="master_bias.fits",
    master_dark="master_dark.fits",
    master_flat="master_flat.fits",
)
write_simple_fits("calibrated.fits", cal_result.data, header=cal_result.header)
