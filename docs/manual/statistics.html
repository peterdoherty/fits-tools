The fits_tools.statistics module provides comprehensive statistical analysis tools for FITS image data.

Basic Statistics from a File

stats

Compute statistics from a FITS file. Returns a StatsResult object with all common measures:

from fits_tools import stats

result = stats("image.fits")
print(result)
# Output:
# Statistics Summary:
#   Mean:   1024.5000
#   Median: 1020.0000
#   Std:    45.3200
#   Min:    850.0000
#   Max:    1250.0000
#   Pixels: 4194304

Access individual fields directly:

print(f"Mean: {result.mean_val:.2f}")
print(f"Std:  {result.std_val:.2f}")
print(f"IQR:  {result.iqr:.2f}")
print(f"MAD:  {result.mad:.2f}")

StatsResult Fields

FieldTypeDescription

max_valfloatMaximum pixel value
mean_valfloatMean pixel value
median_valfloatMedian pixel value
std_valfloatStandard deviation

percentile_25float25th percentile (Q1)

Convert to a dictionary with result.to_dict().

Region Support

Compute statistics on a specific region of the image:

# Statistics on a sub-region
result = stats("image.fits", region=(100, 900, 100, 900))

# Statistics on the DATASEC region
result = stats("image.fits", region="data")

# Statistics on the overscan (BIASSEC) region
result = stats("image.fits", region="bias")

Convenience Functions

If you only need a single statistic:

from fits_tools.statistics import (
    get_image_min, get_image_max, get_image_mean,
    get_image_median, get_image_std,
)

mean = get_image_mean("image.fits")
std = get_image_std("image.fits", region="data")

Array-Based Statistics

array_stats

Compute statistics on a NumPy array directly (no file I/O):

from fits_tools import array_stats
import numpy as np

data = np.random.normal(1000, 50, (2048, 2048))
result = array_stats(data)
print(f"Mean: {result.mean_val:.2f}")
ParameterTypeDefaultDescription
arrnp.ndarray—Input array
roituple or NoneNoneRegion of interest (x1, x2, y1, y2)
skipnaboolFalseIgnore NaN values
compute_extendedboolTrueCompute percentiles, IQR, MAD

Robust Statistics

robust_stats

Compute statistics with sigma-clipping to exclude outliers. This is essential for images with cosmic rays, hot pixels, or other artifacts that would skew standard statistics:

from fits_tools import robust_stats

# From a file
result = robust_stats("image.fits", sigma=3.0, maxiters=5)
print(f"Clipped mean: {result.mean:.2f}")
print(f"Clipped std:  {result.std:.2f}")
print(f"Pixels rejected: {result.num_clipped} ({result.clip_fraction*100:.1f}%)")

# From an array
import numpy as np
data = np.random.normal(1000, 50, (2048, 2048))
result = robust_stats(data, sigma=3.0)

RobustStatsResult Fields

FieldTypeDescription
meanfloatMean of surviving pixels
medianfloatMedian of surviving pixels
stdfloatStandard deviation of surviving pixels
variancefloatVariance of surviving pixels
num_pixelsintNumber of surviving pixels
num_clippedintNumber of rejected pixels
clip_fractionfloatFraction of rejected pixels (0–1)
How sigma-clipping works: The algorithm iteratively computes the mean and standard deviation, then rejects pixels more than sigma standard deviations from the mean. This is repeated for maxiters iterations or until no more pixels are rejected.

CCD-Specific Metrics

Signal-to-Noise Ratio

from fits_tools import calculate_snr

# SNR using the data region for signal, overscan for noise
snr = calculate_snr("image.fits", signal_region="data", noise_region="bias")
print(f"SNR: {snr:.1f}")

Read Noise Estimation

Estimate the read noise from a set of bias frames. The function computes the standard deviation of each bias frame and returns the average:

from fits_tools.statistics import estimate_read_noise

bias_files = ["bias_001.fits", "bias_002.fits", "bias_003.fits"]
rn = estimate_read_noise(bias_files, region="data")
print(f"Read noise: {rn:.2f} ADU")

Dynamic Range

from fits_tools.statistics import calculate_dynamic_range

dr = calculate_dynamic_range("image.fits")
print(f"Dynamic range: {dr:.1f}")

Multi-File Statistics

Average Statistics Across Files

from fits_tools.statistics import calculate_statistics_across_files

# Average statistics across all FITS files in a directory
avg = calculate_statistics_across_files("data/")
print(f"Average mean: {avg['mean']:.2f}")
print(f"Average std:  {avg['std']:.2f}")

# Filter files by header keywords
avg = calculate_statistics_across_files(
    "data/",
    keys={"IMAGETYP": "BIAS"},
    region="data",
)

Convenience wrappers for specific statistics:

from fits_tools.statistics import (
    get_average_mean,
    get_average_median,
    get_average_std,
)

avg_mean = get_average_mean("bias_frames/")
avg_std = get_average_std("bias_frames/", region="data")

Comparing Two Files

from fits_tools.statistics import compare_stats

result = compare_stats("before.fits", "after.fits")
print(result)
# Output:
# Comparison Results:
#   File 1: before.fits
#     Mean: 1024.50,  Std: 45.32
#   File 2: after.fits
#     Mean: 1020.10,  Std: 42.18
#   Differences:
#     Mean: 4.40 (0.43%)
#     Std:  3.14

Trend Analysis

Track how a statistic changes across a sequence of files:

from fits_tools.statistics import analyze_statistics_trend

files = [f"dark_{i:03d}.fits" for i in range(20)]
trend = analyze_statistics_trend(files, statistic="mean")
print(f"Mean trend: {trend['slope']:.4f} per frame")
print(f"Drift: {trend['total_change']:.2f}")
