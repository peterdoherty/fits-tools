Experimental and unimplemented detectors. The public nonlinearity, per-pixel noise, RTS, charge-trap, and amplifier-glow detector entry points are placeholders: they emit warnings and return empty masks. Their draft implementations are experimental and have not been validated for scientific use.

Automated detection of hot, dead, bright, and noisy pixels from calibration frames.

The fits_tools.defects subpackage provides algorithms for automatically detecting pixel defects from calibration frames and building bad pixel masks (BPMs). It builds on the bitmask system described in the previous chapter.

Detection Pipeline Overview

The detection pipeline runs in stages, each analyzing a specific type of calibration frame. Each stage sets specific bit flags in the BPM, and earlier-stage defects are excluded from later-stage statistics:

  1. Bias defects — Pixels with anomalous offset levels (sets PIX_BRIGHT)
  2. Dark hot pixels — Pixels with excess dark current (sets PIX_HOT)
  3. Flat-field defects — Pixels with abnormal quantum efficiency (sets PIX_PRNU_HIGH or PIX_PRNU_LOW)
  4. Structural defects — Entire rows or columns with high defect density (sets ROW_BAD or COL_BAD)

Quick Start: Full Pipeline

create_calibration_bpm

The high-level entry point that runs all detection stages on master bias, dark, and flat frames. It returns the combined BPM and a dictionary of per-stage statistics:

import numpy as np
from fits_tools import get_data
from fits_tools.defects import create_calibration_bpm

master_bias = get_data("master_bias.fits")
master_dark = get_data("master_dark.fits")
master_flat = get_data("master_flat.fits")

bpm, stats = create_calibration_bpm(master_bias, master_dark, master_flat)

# bpm is a uint32 array of defect flags; stats has per-stage results
print(f"Total defective pixels: {stats['total_defects']} "
      f"({stats['total_fraction']:.2%})")
print("Hot pixels from the dark stage:", stats["dark"]["num_defects"])

Individual Detection Functions

Each detection stage can also be run independently on a single master frame. All detection functions return a tuple of (bpm_array, statistics_dict).

Hot Pixels (from Dark)

from fits_tools.defects import detect_hot_pixels

hot_bpm, stats = detect_hot_pixels(master_dark, threshold_sigma=5.0)

print(f"Found {stats['num_defects']} hot pixels "
      f"(threshold {stats['threshold_hi']:.1f} ADU)")

Dead Pixels (from Flat)

from fits_tools.defects import detect_dead_pixels

# Flag pixels whose flat response is below 10% of the median
dead_bpm, stats = detect_dead_pixels(master_flat, threshold_percent=10.0)

print(f"Found {stats['num_defects']} dead pixels")

PRNU Anomalies (from Flat)

from fits_tools.defects import detect_prnu_anomalies, estimate_prnu_model

# Optional: a smooth large-scale model of the flat (tiles of 64x64 pixels),
# so vignetting is not mistaken for pixel-level anomalies
prnu_model = estimate_prnu_model(master_flat, tile_size=64)

# Flag pixels more than 20% above or below the (local) flat response
prnu_bpm, stats = detect_prnu_anomalies(
    master_flat,
    hot_threshold_percent=20.0,
    cold_threshold_percent=20.0,
    local_model=prnu_model,
)
print(f"High-response: {stats['num_hot']}")

Bad Rows and Columns

from fits_tools.defects import detect_bad_rows_cols

# Flag rows/columns where more than 10% of pixels are already defective
structural_bpm, stats = detect_bad_rows_cols(bpm, row_threshold=0.1, col_threshold=0.1)
print(f"Bad rows: {stats['bad_rows']}, bad columns: {stats['bad_cols']}")

Temporal Defects (RTS Noise)

from pathlib import Path
import numpy as np
from fits_tools.defects import detect_temporal_defects

# Pixels whose value fluctuates unusually across a stack of same-type frames
dark_stack = np.stack([get_data(f) for f in sorted(Path("dark_frames/").glob("*.fits"))])
temporal_bpm, stats = detect_temporal_defects(dark_stack, threshold_sigma=5.0)
print(f"{stats['num_defects']} unstable pixels across {stats['n_frames']} frames")

Detection Configuration

The pipeline accepts a configuration dictionary that controls all thresholds. Get the default configuration and modify it:

from fits_tools.defects import get_default_detection_config, create_calibration_bpm

config = get_default_detection_config()
# Sections: "bias", "dark", "dead", "flat", "rows_cols"

# Adjust thresholds
config["bias"]["threshold_adu"] = 50.0      # More sensitive
config["dark"]["threshold_sigma"] = 7.0     # More conservative
config["flat"]["hot_threshold_percent"] = 15.0
config["flat"]["cold_threshold_percent"] = 15.0

bpm, stats = create_calibration_bpm(
    master_bias, master_dark, master_flat,
    config=config,
)

Saving and Loading BPMs

Saving to FITS

BPM FITS files are self-describing: they include bit definitions in the header and a DQ_DEF binary table extension:

from fits_tools.defects import save_bpm_to_fits

# Passing the detection stats records counts and parameters in the header
save_bpm_to_fits(bpm, "detector_bpm.fits", stats=stats)

The resulting FITS file contains:

  • Primary HDU — The BPM array with metadata headers (total defect counts, per-bit counts, detection parameters)
  • DQ_DEF extension — A binary table listing each bit flag's index, value, name, and description

Loading from FITS

from fits_tools.defects import load_bpm_from_fits

bpm, metadata = load_bpm_from_fits("detector_bpm.fits")
print(f"BPM shape: {bpm.shape}")
print(f"Total defects: {metadata['total_bad']} ({metadata['bad_fraction']:.2%})")
print(metadata["defect_counts"])

Validating a BPM File

from fits_tools.defects import validate_bpm_fits

# Raises ValueError if the array is not a 2-D unsigned-integer BPM;
# a header/array count mismatch only logs a warning.
try:
    validate_bpm_fits(bpm, metadata)
    print("BPM file is valid")
except ValueError as error:
    print(f"Invalid BPM: {error}")

Merging BPMs

from fits_tools.defects import merge_bad_pixel_maps, save_bpm_to_fits

# Merge a stage-specific defect map into a cumulative master BPM
# (bitwise OR, so every flag from both is kept)
save_bpm_to_fits(hot_bpm, "dark_stage_defects.fits")
merge_stats = merge_bad_pixel_maps(
    "detector_bpm.fits",            # existing cumulative BPM (or None)
    "dark_stage_defects.fits",      # new defects
    "detector_bpm_merged.fits",     # output
    stage="DARK",                   # recorded in the header
)
print(merge_stats["PIX_HOT"]["count"], "hot pixels in the merged BPM")
