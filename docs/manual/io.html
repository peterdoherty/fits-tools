File I/O

Reading data and headers, writing FITS files, and inspecting file structure.

The fits_tools.io module provides functions for reading and writing FITS files. These sit on top of Astropy's astropy.io.fits and add error handling, region support, and convenience features.

Reading Data

get_data_and_header

The most common way to read a FITS file. Returns both the image data (as a NumPy array) and the header:

from fits_tools import get_data_and_header

data, header = get_data_and_header("image.fits")
print(f"Shape: {data.shape}")
print(f"Object: {header['OBJECT']}")
ParameterTypeDefaultDescription
filepathstr or Path—Path to the FITS file
hduint0HDU index to read
memmapboolFalseUse memory mapping (for large files)
Note: When memmap=False (the default), the data is copied into a regular NumPy array and the file is closed. When memmap=True, the data is memory-mapped and the file must remain accessible for the lifetime of the array.

get_data

Read just the data array, with optional region selection:

from fits_tools import get_data

# Read the full image
data = get_data("image.fits")

# Read a specific region (start_col, end_col, start_row, end_row)
subregion = get_data("image.fits", region=(100, 500, 100, 500))

# Read the data section defined by the DATASEC keyword
data_region = get_data("image.fits", region="data")

# Read from a specific HDU of a multi-extension file
ext_data = get_data("multi_ext.fits", hdu=1)
Region convention: Region tuples use column-first ordering: (start_col, end_col, start_row, end_row). This matches the FITS pixel coordinate convention (x, y) rather than NumPy's (row, col) ordering. Coordinates are 0-indexed with exclusive end values.

The region parameter accepts several forms:

ValueMeaning
None or "full"The entire image
"data"Region defined by the DATASEC keyword
"bias"Region defined by the BIASSEC keyword
"trim"Region defined by the TRIMSEC keyword
"dark"Region defined by the DARKSEC keyword
(x1, x2, y1, y2)Explicit 0-indexed coordinates

get_header

Read just the header, without loading the image data:

from fits_tools import get_header

header = get_header("image.fits")
print(f"Exposure time: {header['EXPTIME']} seconds")

get_all_data

Read image data from all HDUs in a Multi-Extension FITS (MEF) file:

from fits_tools import get_all_data

# Returns a list of arrays, one per image HDU
arrays = get_all_data("multi_ext.fits")
print(f"Found {len(arrays)} image extensions")

# Return as a dictionary keyed by EXTNAME
arrays_dict = get_all_data("multi_ext.fits", return_dict=True)
sci_data = arrays_dict["SCI"]

Memory-Mapped Access

For very large files, use open_all_data_memmap as a context manager:

from fits_tools.io import open_all_data_memmap

with open_all_data_memmap("large_file.fits") as arrays:
    for arr in arrays:
        print(f"Shape: {arr.shape}, Mean: {arr.mean():.2f}")
# File is automatically closed when the context exits

HDU Discovery

Counting and Listing HDUs

from fits_tools import count_hdus, get_image_hdus

# Total number of HDUs (including primary)
n = count_hdus("image.fits")
print(f"Total HDUs: {n}")

# Indices of HDUs that contain image data
indices = get_image_hdus("image.fits")
print(f"Image HDUs at indices: {indices}")

# Filter by extension name
sci_indices = get_image_hdus("image.fits", extname="SCI")

get_image_shape

Get the shape of an image HDU without loading the data:

from fits_tools import get_image_shape

shape = get_image_shape("image.fits")
print(f"Image dimensions: {shape}")  # e.g. (2048, 2048)

inspect_fits

Print a summary of a FITS file's structure to the console:

from fits_tools import inspect_fits

inspect_fits("multi_ext.fits")
# Output:
# HDU  Type         EXTNAME   Shape           BITPIX
# 0    PrimaryHDU             (2048, 2048)    16
# 1    ImageHDU     SCI       (2048, 2048)    -32
# 2    ImageHDU     ERR       (2048, 2048)    -32

Writing Data

write_simple_fits

Write a single image array to a FITS file:

import numpy as np
from fits_tools import write_simple_fits

data = np.zeros((512, 512), dtype=np.float32)

# Basic write: path first, then data
write_simple_fits("output.fits", data)

# Write with a header
from astropy.io import fits
header = fits.Header()
header["OBJECT"] = "Test Image"
header["EXPTIME"] = 60.0
write_simple_fits("output.fits", data, header=header, overwrite=True)
ParameterTypeDefaultDescription
datanp.ndarray—Image array to write
filepathstr or Path—Output file path
headerfits.Header or NoneNoneFITS header to include
overwriteboolFalseOverwrite existing file
compressboolFalseUse FITS tile compression

safe_write

Write an HDUList to disk atomically. The file is first written to a temporary location, then moved into place. This prevents partial writes from corrupting existing files:

from fits_tools.io import safe_write
from astropy.io import fits

hdul = fits.HDUList([fits.PrimaryHDU(data)])
safe_write(hdul, "output.fits", overwrite=True, dry_run=False)

Set dry_run=True to log the intended write without actually writing anything.

Copying Headers

from fits_tools import copy_header

# Copy a header, excluding structural keywords
new_header = copy_header(header, exclude_keys=["NAXIS", "NAXIS1", "NAXIS2"])

Error Handling

I/O functions raise specific exceptions from the fits_tools.exceptions module:

ExceptionWhen Raised
FileHandlingErrorFile not found or cannot be opened
InvalidHDUIndexErrorHDU index is out of range
FileOverwriteErrorFile exists and overwrite=False
HeaderKeywordErrorRequired section keyword missing
RegionErrorRegion is out of bounds
from fits_tools import get_data
from fits_tools.exceptions import FileHandlingError, InvalidHDUIndexError

try:
    data = get_data("missing.fits")
except FileHandlingError as e:
    print(f"Cannot open file: {e}")

try:
    data = get_data("image.fits", hdu=99)
except InvalidHDUIndexError as e:
    print(f"Bad HDU index: {e}")
